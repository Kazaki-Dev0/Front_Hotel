API endpoints esperados:
  • POST /api/Hoteis - body JSON com pelo menos nome (ou name); retornará o hotel criado.
  • GET /api/Hoteis - lista de hotéis.
  • POST /api/Quartos - body JSON com pelo menos nome e hotelId (ou equivalente); retornará o quarto criado.
  • GET /api/Quartos - lista de quartos.
Observação: a API deve permitir CORS para requests do navegador.
